# Simulador de Inventario
- Puedes consultar el inventario que hay en una tienda (tu la administras, asi que puedes vender lo que quieras). Añadir productos, restarlos (por ventas, o alguna otra razón), ver el precio de los productos y consultar cuántas unidades hay de cada producto.

- Pasos a seguir:
  Abrir un menú en el que se pregunte al usuario qué quiere hacer: Si agregar productos (1), quitar productos(2), buscar        productos (3) o cerrar el programa(4).
  - Si se elige 1: Agregar productos (con su precio) y guardarlos en un archivo de texto.
  - Si elige 2: Pedir el nombre de el producto y el numero de unidades a restar.
  - Si elige 3: Pedir el nombre de el producto y arrojar cuantas unidades hay.
  - Si elige 4: Se cierra el programa.
  Una vez terminada cada acción, se mostrará el menú al usuario.
