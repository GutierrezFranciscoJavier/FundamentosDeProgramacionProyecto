# Simulador de Inventario (con calculadora de cambio y descuento incluida)
- Puedes consultar el inventario que hay en una tienda (tu la administras, asi que puedes vender lo que quieras). Añadir productos, restarlos (por ventas, o alguna otra razón), ver el precio de los productos y consultar cuántas unidades hay de cada producto.

- Pasos a seguir:
  Abrir un menú en el que se pregunte al usuario qué quiere hacer: Si agregar productos (1), ver la lista de productos(2), calcular el cambio (3), hacer compras de los productos de el inventario (4) o cerrar el programa(5).
  - Si se elige 1: Agregar productos (con su precio) y guardarlos en un archivo de texto.
  - Si elige 2: Pedir el nombre de el producto y despliega el nombre con sus unidades.
  - Si elige 3: Pedir al usuario dos números, y que seleccione la operación que quiere hacer (cambio o descuento).
  - Si elige 4: Pide al usuario el nombre de el producto que quiere comprar (mostrándole la lista) y la cantidad que desea comprar. Resta la cantidad que compró de la lista y no deja comprar más de lo que ya tienes.
  - Si elige 5: Se cierra el programa.
  Una vez terminada cada acción, se mostrará el menú al usuario.
